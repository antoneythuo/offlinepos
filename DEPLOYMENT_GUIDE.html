Deployment Guide

Step-by-step setup for a new computer — from zero to a clickable desktop app.

1 Prerequisites

Install these once on every machine that will run the POS system.

Node.js 20 LTS Required

Download the Windows Installer (.msi) from nodejs.org — choose the LTS version. Accept all defaults.

Verify the installation by opening Command Prompt and running:

node -v
npm -v

Both commands should print version numbers.

MySQL 8.x Required

Download MySQL Installer for Windows from dev.mysql.com. During setup choose Server Only or Developer Default. Set a root password and keep port 3306.

After installation, open MySQL Command Line Client and run:

CREATE DATABASE pos_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'pos_user'@'localhost' IDENTIFIED BY 'pos_password';
GRANT ALL PRIVILEGES ON pos_db.* TO 'pos_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;

⚠️ If you use a different username or password, remember to update config.json in the next step.

2 Project Setup

  1. Copy the project folder Copy the entire offline-pos-system folder to the target machine, for example to C:\POS\offline-pos-system\
  2. Create config.json Open Command Prompt, navigate to the project folder and copy the example config: 
    cd C:\POS\offline-pos-system
copy config.example.json config.json
    Open config.json and confirm the values match your MySQL setup: 
    {
  "database": {
    "host": "127.0.0.1",
    "port": 3306,
    "user": "pos_user",
    "password": "pos_password",
    "database": "pos_db"
  }
}
  3. Install dependencies 
    npm install
    This downloads all required packages. Takes 3–5 minutes on first run.
  4. Run database migrations 
    npx knex migrate:latest --knexfile knexfile.ts
    Creates all 27 database tables.
  5. Seed default data 
    npx knex seed:run --knexfile knexfile.ts
    Inserts default roles, admin user, General category, Piece unit, and all default settings.

✅ At this point you can test the app with npm run dev before building the installer.

3 Build the Installer

This compiles all code and packages it into a Windows .exe installer — no Command Prompt needed to run the final app.

Optional: Add an app icon

Create a build folder inside the project and place a icon.ico file (256×256 px) inside it. Skip this step to use the default Electron icon.

mkdir C:\POS\offline-pos-system\build

Run the build

cd C:\POS\offline-pos-system
npm run dist

This takes 5–15 minutes. When complete, the installer is at:

C:\POS\offline-pos-system\dist\Offline POS System Setup 1.0.0.exe

ℹ️ The build process runs electron-vite build then electron-builder automatically. You don't need to run them separately.

4 Install the Application

Double-click Offline POS System Setup 1.0.0.exe. The installer will:

  • Ask where to install (default: C:\Program Files\Offline POS System\)
  • Create a Desktop shortcut
  • Create a Start Menu entry
  • Register the app for uninstall via Windows Settings → Apps

After installation, launch the app from the desktop shortcut or Start Menu. No Command Prompt required.

⚠️ MySQL must be running before you open the app. See the next section to make it start automatically on boot.

5 MySQL Auto-Start on Boot

MySQL should start automatically when Windows boots. To verify and configure this:

  1. Press Win + R, type services.msc, press Enter
  2. Find MySQL80 in the list
  3. Check that its status is Running
  4. If not running: right-click → Start
  5. To ensure it starts on boot: right-click → Properties → Startup type → Automatic

✅ Once set to Automatic, MySQL will start silently every time Windows boots — the POS app will always be able to connect.

6 Updating the App

When you receive an updated version of the source code:

  1. Replace the project files in C:\POS\offline-pos-system\
  2. Run the following commands: 
    cd C:\POS\offline-pos-system
npm install
npx knex migrate:latest --knexfile knexfile.ts
npm run dist
  3. Run the new installer from the dist\ folder — it will update the existing installation.

ℹ️ Migrations are safe to run multiple times. They only apply changes that haven't been applied yet — your data is never deleted.

7 Troubleshooting

ProblemSolution
App opens but shows "Unable to connect"MySQL is not running. Open services.msc and start MySQL80.
"Access denied for user" errorCheck that config.json credentials match your MySQL user.
Blank white screen on launchOpen DevTools (Ctrl+Shift+I) and check the Console tab for errors.
Build fails with "icon not found"Remove the icon: lines from electron-builder.yml or add a valid build/icon.ico file.
npm install failsEnsure Node.js 20 is installed and you have internet access during setup.
Port 3306 already in useAnother MySQL instance is running. Stop it or change the port in config.json.
Migration fails with "Table already exists"Safe to ignore — migrations are idempotent. Run migrate:latest again.
Print dialog doesn't openEnsure a printer is installed in Windows. The app uses the system print dialog.
